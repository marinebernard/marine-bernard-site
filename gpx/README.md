# Traces GPX — Coups de cœur

Placer ici les fichiers GPX téléchargés depuis Komoot pour chaque sentier coup de cœur.

Sur chaque sortie sur Komoot → clique sur les trois points → « Exporter » → « GPX ». Dépose ensuite le fichier téléchargé dans ce dossier avec le nom exact ci-dessous — les boutons « Télécharger GPX » de la page `pages/parcours-komoot.html` pointent directement vers ces fichiers.

Nommer les fichiers :
- `cap-blanc-nez.gpx`
- `terrils-haillicourt.gpx`
- `haute-vallee-lawe.gpx`
- `baie-authie.gpx`
- `wimereux.gpx`
- `val-souchez.gpx`
